# sygmaz/.github

This repository holds the public profile shown at [github.com/sygmaz](https://github.com/sygmaz). GitHub renders `profile/README.md` on the organization page.

- `profile/README.md`: the profile page.
- `profile/assets/`: the two recordings of the website entrance, captured on 21 November 2026 from a local production build of the `cinematic-language-entry` branch of `sygmaz/sygmaz-web` (`SITE_MODE=live FEATURE_CINEMATIC_ENTRY=true`). The desktop take is English at 1440 × 900 and the phone take is Bangla at 390 × 844, recorded with Playwright in Chrome and encoded as GIF.

The website code is in `sygmaz/sygmaz-web` and the planning record is in `sygmaz/sygmaz-planning`. Both are private.

To refresh the recordings after the entrance changes, rebuild that branch with the same flags, record the chooser tap at both sizes and replace the two GIFs. Keep each under about 5 MB so the page loads quickly.
